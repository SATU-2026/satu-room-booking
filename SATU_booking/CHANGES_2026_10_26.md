# สิ่งที่ปรับก่อนทดลอง GitHub Pages

- ค้นหารายการด้วยเบอร์โทรศัพท์ **หรือ** เลขทะเบียนนักศึกษา (ทั้งโหมด demo/live)
- หลังจอง เก็บกุญแจจัดการรายการเฉพาะใน localStorage ของเบราว์เซอร์นี้ เพื่อไม่ต้องกรอกรหัสยาวทุกครั้ง
- ไม่แสดงกุญแจยาวบนหน้าจอสำเร็จ แต่ดาวน์โหลดไฟล์สำรองได้ (เก็บไฟล์นี้เป็นความลับ)
- หากย้ายเครื่อง/ล้าง localStorage ต้องใช้รหัสจากไฟล์สำรองหรือขอเจ้าหน้าที่ช่วยเหลือ
- Supabase ติดตั้งใหม่: ใช้ 01_schema.sql รุ่นนี้; ระบบเก่าที่รัน SQL แล้ว: รัน 04_lookup_phone_or_student.sql เพิ่ม
- ระบบยังคงการยืนยันสิทธิ์ตอนดูรายละเอียด/แก้ไข/ยกเลิก/จัดการไฟล์ใน backend ไม่อนุญาตให้คนที่ทราบเบอร์โทรอย่างเดียวแก้ได้
- ฟีเจอร์ปิดห้องเฉพาะช่วง, กดส่งซ้ำ, เหตุผลไม่อนุมัติ, ช่องทางติดต่อ มีอยู่แล้วในต้นฉบับ
- แถบที่เคยให้เอาออกจากภาพในแชทก่อนหน้า ยังระบุองค์ประกอบไม่ได้ชัดเจน จึงไม่ได้ลบส่วนอื่นโดยสุ่ม

**ข้อควรระวัง:** การค้นด้วยเลขทะเบียน/โทรศัพท์แสดงข้อมูลสรุปการจองแก่ผู้ที่ทราบตัวระบุ ควรประเมินความเป็นส่วนตัวก่อนเปิดใช้งานจริง
